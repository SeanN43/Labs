A collection of experimental physics labs where I collected, cleaned, analysed, and visualised real-world measurement data and then validated it against theoretical predictions. These textbooks are not real world data sets, it's noisy, real world measurements taken by hand in a lab. Working with them meant

Cleaning messy data: Irregular spacing, measurement noise, and inconsistent formatting had to be handled before any analysis was possible

Analysis with NumPy: Structuring raw arrays into something usable, computing derived quantities

Visualising results with Matplotlib: Plotting experimental data with clear labelling, legends, and annotations to make patterns interpretable.

Validating against theory: Overlaying theoretical predictions (e.g. maxima/minima positions) on experimental plots to assess how well the data matched expected physical models, and reasoning about the sources of discrepancy.

Also features a self directed implemenetation of Grover's Algorithm in Qiskit on 2-5 qubits.
